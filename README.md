# Mori · 智能体工作台

使用 Rust + GPUI Kit 0.6.1 构建的原生桌面主界面，参考 WorkBuddy 的任务工作台组织方式。

```sh
cargo run --offline
```

## 当前功能

- 暖白与森林绿配色，支持浅色 / 深色主题切换。
- 工作台、任务描述输入、四类任务模板和分类筛选。
- 模板填入输入框，可编辑后创建任务。
- 最近任务列表、任务详情、新建任务。
- `⌘N` 新建任务，`⌘Enter` 创建任务，`Enter` 换行，`⌘Q` 退出。
- 默认窗口 1220 × 820，最小窗口 940 × 680；主内容和任务列表独立滚动。

当前是交互界面原型：未接入模型、工具执行与文件系统，任务仅保存在内存中，退出应用后清空。界面不展示虚构的执行结果。

## 代码结构

- `src/main.rs`：窗口、资源、快捷键及启动。
- `src/theme.rs`：产品主题与语义颜色。
- `src/workspace.rs`：工作台布局、输入状态、模板和会话内任务。

## 验证

```sh
cargo fmt --check
cargo check --offline
cargo clippy --offline -- -D warnings
cargo build --offline
```

窗口验收：模板填入 → 编辑内容 → 创建任务 → 切换历史任务 → 新建任务；检查空输入禁用、主题切换、快捷键与窗口缩小时的滚动。
