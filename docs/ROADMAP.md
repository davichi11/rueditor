# 路线图

本项目按里程碑（M）与优先级（P）推进。已经完成的阶段保留在这里作为历史记录，未完成的部分按优先级排列。

## 已完成

| 里程碑 | 内容 |
| --- | --- |
| M0 | 项目标识统一为 `Rueditor` / `rueditor`，统一 Cargo 包、默认运行目标、窗口标题和应用 ID。 |
| M1 | 跨平台应用壳、窗口配置和平台主修饰键快捷键。macOS 使用 Command，Windows/Linux 使用 Ctrl。 |
| M2 | 新建、打开、拖入、保存、另存为；后台文件 I/O；UTF-8、UTF-8 BOM、LF 和 CRLF 处理；原子保存。 |
| M3 | 多标签文档工作区；每个文档独立维护文本、选区、滚动、撤销历史、路径、编码、换行格式和未保存状态。 |
| M4 | 常见文件扩展名自动识别；手动切换语言；语法高亮和代码折叠。 |
| M5 | 查找、替换、下一个匹配、上一个匹配和全部替换；全部替换支持一次撤销。 |
| P0 | 外部文件修改保护：保存前校验文件指纹，拒绝覆盖外部改动。 |
| P1 | 文档级编辑设置；跳转、复制、删除、移动、缩进和大小写转换等文本/行操作；普通文本与正则搜索替换；大小写、全词匹配和捕获组替换。 |
| P2 | Markdown 文档预览：右侧分栏实时渲染正文，标题、列表、引用、代码块和表格按 CommonMark 与 GFM 解析。 |

## 待办

### 优先

- **签名与公证**：打包脚本目前只产出未签名 App，正式分发需要开发者证书 identity 和 notarization 流程。
- **Release 流水线**：为每个版本自动产出 `Rueditor.dmg` 并附加到 GitHub Release。
- **CI**：把格式化、检查、clippy、测试四步接到 GitHub Actions，避免依赖人工执行。

### 功能

- 外部修改后的自动重新载入与冲突合并（目前只拒绝覆盖）。
- 完整外观设置：主题切换、字号、行高，目前只跟随系统深浅色。
- 分栏编辑、文件夹级搜索、自动保存、Unicode 正规化。
- 超大文件的分块加载与性能优化。
- 中文输入法、原生拖放、最小窗口布局在 Windows/Linux 的实机验收。

### 明确不做

- LSP、调试器、内置终端、Git 集成、插件体系、云同步。这些属于 IDE 的职责，不是本项目的目标。
