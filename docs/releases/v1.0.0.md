# Rueditor 1.0.0

首个稳定版本。Rueditor 是一个基于 Rust 与 GPUI 构建的原生跨平台文本编辑器，定位是 Notepad++ / CotEditor 的现代替代品：打开即编辑，不做 IDE。

从第一行代码到 1.0.0 用时约九周、13 次提交。这个版本不是"功能齐全"，而是"该有的都有、边界说清楚了"——核心编辑、多文档、语法高亮、折叠、查找替换、Markdown 预览全部可用，编码与换行保真、外部修改保护这类容易被忽略的正确性问题也都处理了。

## 亮点

- **窗口出现就能打字。** 没有欢迎页、没有插件加载、没有工作区索引。
- **不擅自改你的文件。** UTF-8 BOM、CRLF 原样保留；非法 UTF-8 或混合换行直接报错，而不是猜一个编码写回去；保存前校验文件指纹，检测到外部修改就拒绝覆盖。
- **37 种语言模式。** 高亮全部由 tree-sitter 提供，JS/TS/JSX/TSX 按真实块结构折叠，Python 按缩进分支折叠，YAML 按层级折叠。
- **正则替换带捕获组。** 支持大小写、全词、替换当前与全部替换，全部替换可一次撤销。
- **Markdown 实时预览。** 可拖拽的右侧分栏，按 CommonMark 与 GFM 渲染，代码块复用编辑器高亮主题。

## 新增功能

### 文档与工作区

- 多标签工作区，每个文档独立维护文本、选区、滚动位置、撤销历史、路径、编码、换行格式和未保存状态。
- 重复打开同一路径时定位到已有标签，不产生副本。
- 支持把多个文件拖入窗口，逐个后台加载；单个文件失败不会阻塞其他文件。
- 支持命令行传参和文件 URL 打开（macOS 访达「打开方式」）。
- 关闭标签或退出时确认未保存修改；保存失败、取消保存或取消关闭都不会丢内容。

### 文件与编码

- 新建、打开、保存、另存为，文件读写与哈希校验在后台完成。
- 原子保存，避免写入中途失败损坏原文件。
- 保留 UTF-8 / UTF-8 BOM 与 LF / CRLF 原格式。
- 拒绝非法 UTF-8、混合换行和孤立 CR，并保持原文件不变。

### 语法高亮与折叠

内置 37 种语言模式（含纯文本回退）：

| 类别 | 支持 |
| --- | --- |
| 系统与脚本 | Shell / Bash、Makefile、CMake、Diff |
| 通用编程 | C、C++、Java、Go、C#、Kotlin、Swift、PHP、Ruby、Lua、Scala、Elixir、Zig、SQL |
| 前端 | JavaScript、JSX、TypeScript、TSX、HTML、CSS |
| 数据与配置 | JSON、TOML、YAML、XML、Properties、INI、Dotenv、Protocol Buffers、GraphQL |
| 文档 | Markdown |
| 其他 | Rust、Python、纯文本 |

- 检测顺序：显式扩展名 → 特殊文件名（Makefile、CMakeLists.txt、Gemfile、`.bashrc` 等）→ 首行 shebang（支持 `/usr/bin/env` 与 `env -S`）→ 纯文本。
- `.h` 归 C，`.hpp` / `.hh` / `.hxx` 与大写 `.C` 归 C++；`.xml` / `.svg` / `.xsd` / `.xsl` / `.plist` 使用 XML 语法，`.ini` / `.cfg` 使用 INI 语法。
- 高亮区分函数、方法、参数、属性、JSX 标签、字符串转义与模板插值。
- 折叠收起时完整隐藏块体，并保留内层折叠状态。
- 所有语言均可通过「文本 → 语言」手动切换，未知类型回退纯文本。

### 查找与替换

- 普通文本与正则两种模式，支持大小写匹配、全词匹配。
- 下一个 / 上一个匹配、替换当前、全部替换。
- 正则替换支持捕获组引用；无效正则不会写回文档。
- 搜索会话与编辑设置按文档独立保存。

### 格式化

- JSON 格式化，并对部分常见的非严格 JSON 自动修复后格式化。
- 纯文本格式化：清理行尾空白、统一文件末尾换行。

### Markdown 预览

- 「显示 → Markdown 预览」或 `⇧⌘V` 打开右侧分栏，可拖拽调整宽度，内容随正文实时刷新。
- 按 CommonMark 与 GFM 解析，支持标题、列表、引用、表格、删除线和代码块。
- 预览状态按文档保存，切换标签后各自保留；非 Markdown 文档打开时会提示不支持。

### 编辑与界面

- 文档级设置：行号、自动换行、显示空白、智能缩进、自动闭合括号、Tab 宽度（2/4/8）。
- 行操作：跳转到行、复制 / 删除 / 移动当前行、缩进 / 反缩进、大小写转换、清理行尾空白。
- 原生菜单栏，按「文件 / 编辑 / 格式 / 显示 / 文本 / 查找 / 窗口 / 帮助」组织，不使用拥挤的顶部工具栏。
- 主题跟随系统深浅色（Rueditor Light / Rueditor Dark），14px 界面字号、13px 等宽字号。
- 标签栏显示当前文件与未保存状态；语言、编码、换行格式与缩进信息集中在状态栏。

## 工程

- 依赖升级至 `gpui-kit` 0.8.0。
- 代码规模约 7.3k 行 Rust，其中 2.7k 行为测试；84 个测试覆盖文件读写、编码与换行、异步多文档流程、未保存状态、格式化、语言切换、折叠以及查找替换。
- 最低 Rust 版本 1.85（edition 2024），已在 `Cargo.toml` 声明 `rust-version`。
- 采用 MIT 许可证。
- 提供 macOS 打包脚本，可产出 `.app` 与 `.dmg`，支持 codesign 签名身份传入。

## 已知限制

- 只处理 UTF-8 和 UTF-8 BOM，不自动转换其他字符编码。
- 检测到外部修改时只拒绝保存，尚不支持自动重新载入与冲突合并。
- 外观只跟随系统深浅色，主题切换和字号调整尚未产品化。
- 未针对超大文件做分块加载或专门优化。
- 未实现分栏编辑、文件夹级搜索、插件、LSP、内置终端、云同步、自动保存和 Unicode 正规化。
- **平台支持实测范围**：目前仅在 macOS 上完整验证。Windows / Linux 的原生窗口、中文输入法、原生拖放和最小窗口布局尚未实机验收。

## 安装

### macOS（推荐）

下载附件 `Rueditor.dmg`，拖入「应用程序」。

当前构建未签名、未公证，首次打开需要右键点图标 →「打开」，或执行：

```sh
xattr -dr com.apple.quarantine /Applications/Rueditor.app
```

### 从源码构建

需要 Rust 1.85 或更高。

```sh
git clone git@github.com:davichi11/rueditor.git
cd rueditor
cargo run --release
```

自行打包 App 与 DMG：

```sh
./scripts/package-macos.sh --offline --dmg
```
